# 接入 Google Sheet（只需做一次）

1. 打开 Sheet「MYPG 2026 四组晚餐准备」→ 菜单栏 **Extensions → Apps Script**
2. 把左边默认的 `Code.gs` 内容全部删掉，粘贴本目录的 `Code.gs`，Ctrl/Cmd+S 保存
3. 右上角 **Deploy → New deployment**
   - 齿轮图标选 **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - 点 Deploy，首次会要求授权（选自己的 Google 账号 → Advanced → Go to … (unsafe) → Allow）
4. 复制得到的 **Web app URL**（`https://script.google.com/macros/s/…/exec`），发给 Claude 填进 `index.html` 的 `API_URL`
5. 第一次访问时脚本会自动在 Sheet 里新建两个标签页：
   - **菜单**：香港园菜单，换餐厅时直接改这一页（「启用」填 N 可隐藏某道菜）
   - **网页数据**：每人每月的细项（点菜、自带、付款勾选）

## 以后改了脚本怎么更新
Deploy → **Manage deployments** → 铅笔图标 → Version 选 **New version** → Deploy。网址不变。

## 脚本会往 Sheet2 写什么
- 名字 × 本月列：A / C / NA（新朋友会在名单末尾插一行）
- 「拼菜总数」「预订菜品」「自制佳肴」：每次有人改动都重新生成本月那一列
- 「订餐餐厅」：为空时填「香港园」
- 「取餐同工」不动，仍由你手填
